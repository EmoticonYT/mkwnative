What is MKWnative?

MKWnative is a native replay layer designed to run Mario Kart World directly on Apple Silicon Macs. Unlike traditional emulators that translate CPU instructions through JIT or interpretation, MKWnative executes the game’s original ARM64 binary code natively on the host Apple Silicon CPU cores.

Graphics calls from the game's NVN graphics pipeline are translated directly to Apple Metal, allowing the game to run with minimal overhead, accurate timing, and full hardware acceleration.

How it Works

Native ARM64 Execution: Switch 2 binaries run directly on Apple Silicon without CPU instruction translation.
Metal Graphics: NVN rendering commands and compute shaders are rebuilt natively on Apple Metal.
Self-Contained Installer: Packages the game dump and native runner into a standalone macOS application.
Controller Support: Native input support for Nintendo Switch Pro Controllers, Joy-Cons, and standard gamepads.

Getting Started

  1. Dump your legally owned game cartridge to obtain your RomFS and ExeFS files.
  2. Download and open the MKWnative Installer application below.
  3. Select your game folder containing the dumped files.
  4. Install and run the generated application on your Mac.
